# Hardware used for the full 50-file run

- **Where:** my own laptop (Lenovo Legion 7i)
- **GPU:** NVIDIA GeForce RTX 4060 Laptop GPU, 8 GB (driver 616.64)
- **CPU:** Intel Core i7-14700HX, 20 cores / 28 threads (WSL2 limited to 24 threads)
- **RAM:** 16 GB (WSL2 limited to 12 GB)
- **Disk:** TODO (SSD / HDD). The dataset was stored on the WSL2 ext4 virtual disk
- **OS:** Windows 11 Home, with the run inside WSL2 Ubuntu 26.04 and Python 3.11
- **Full run time (50 files, start to finish):** The full run took 5687s (94.78m)
